# feature/model-aliases — все alias модели в приложении

Часть проекта [Resume Classifier](../../tree/main). Влита в `main` через [PR #24](../../pull/24).
Вторая из трёх веток с доработками ДЗ 3 после защиты.

## Что сделано

- При старте приложение загружает модели **всех alias** реестра (`champion`, `demo-v1`,
  `demo-v2`…). Если на одну версию указывают несколько alias, она загружается один раз.
- В `/process` можно выбрать модель: `{"model": "demo-v2", "texts": [...]}`, по умолчанию
  `champion`. Неизвестный alias — `404` со списком доступных.
- `GET /api/v1/model` показывает все версии реестра: alias, кандидат, версия датасета, размер
  train, метрики на validation и test.
- Smoke-тест проверяет версию модели по ответу `/process`: после переноса alias она не меняется до
  перезапуска приложения.

Приложение с тремя моделями на настоящих данных занимает около 380 МБ из 512.

## Как проверить

```bash
curl http://localhost:8000/api/v1/model
curl -X POST http://localhost:8000/process -H 'Content-Type: application/json' -d '{"model": "demo-v2", "texts": ["Бухгалтер, 1С"]}'
```
