# feature/process — модель из реестра в веб-сервисе

Часть проекта [Resume Classifier](../../tree/main). Влита в `main` через [PR #20](../../pull/20),
релиз `v0.2.0`. Последняя из четырёх веток с MLflow.

## Что сделано

- `model.py` — при старте приложение один раз загружает из реестра MLflow версию модели, на
  которую указывает alias `champion`;
- `POST /process` — классифицирует резюме загруженной моделью;
- `GET /api/v1/model` — показывает, какая модель сейчас в памяти;
- настройки `MLFLOW_TRACKING_URI`, `MLFLOW_MODEL_NAME`, `MLFLOW_MODEL_ALIAS`;
- в группу `web` добавлены mlflow-skinny, pandas и scikit-learn: они нужны приложению, чтобы
  загрузить модель и предсказывать. Полный mlflow и matplotlib остались в группе `ml`;
- лимит памяти приложения поднят с 256 до 512 МБ: с моделью, обученной на настоящих данных,
  оно занимает около 335 МБ;
- 16 новых тестов, всего 54, покрытие 98% (порог 90%);
- версия поднята до `0.2.0`: у сервиса появилась новая функциональность.

## Эндпоинты

| Путь | Что возвращает |
|---|---|
| `POST /process` | сферу для каждого текста и сведения о модели; 503, если модель не загружена |
| `GET /api/v1/model` | имя, alias, версию и `run_id` загруженной модели; 503, если модель не загружена |

Запрос — от 1 до 32 текстов, каждый от 1 до 20 000 символов, лишние поля запрещены:

```bash
curl -X POST http://localhost:8000/process -H 'Content-Type: application/json' -d '{"texts": ["Python, FastAPI, PostgreSQL, разработка API"]}'
```

```json
{
  "predictions": [{"index": 0, "category": "backend"}],
  "model": {
    "name": "resume-classifier",
    "alias": "champion",
    "version": "1",
    "run_id": "4a5971d1c2d94647bfb20de652fd0185",
    "model_uri": "models:/resume-classifier/1"
  }
}
```

Это ответ модели, обученной на учебном наборе. `index` — номер текста в запросе, блок `model`
показывает, какая именно версия ответила.

## Решения

**Модель загружается один раз.** Загрузка идёт при старте приложения, а не на каждый запрос, и
вынесена в отдельный поток, чтобы не блокировать event loop. Предсказание тоже считается в
потоке: scikit-learn синхронный.

**Сервис стартует и без модели.** Если MLflow недоступен или alias не назначен, приложение
пишет в лог `model_not_loaded` и запускается: служебные эндпоинты работают, а `/process` и
`/api/v1/model` отвечают 503.

**Смена модели — перенос alias и перезапуск.** В коде нет номера версии: приложение знает только
имя модели и alias. Чтобы выкатить другую версию или откатиться, достаточно перенести alias и
перезапустить приложение, пересборка образа не нужна.

**`/process` без `/api/v1`.** Путь задан условием задания.

## Как проверить

На учебном наборе, настоящий датасет в git не хранится:

```bash
cp .env.example .env
TRAIN_DATA_PATH=/input/resumes_demo.csv docker compose up -d --build
curl http://localhost:8000/api/v1/model
```

Смена версии модели без пересборки:

```bash
docker compose exec app python -m resume_classifier.ml.registry --version 2
docker compose restart app
curl http://localhost:8000/api/v1/model
```

Первый ответ — `"version":"1"`, после перезапуска — `"version":"2"`. Всё то же самое делает
`./scripts/smoke.sh`: обучение, запрос к `/process`, смена alias и проверка новой версии.

Документация API — http://localhost:8000/docs, интерфейс MLflow — http://127.0.0.1:5050.
